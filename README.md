# Python Security Log Analysis & Threat Detection

## About the Project

This project was developed as part of my Cyber Security studies at TU Dublin. It is a Python-based tool designed to analyse security logs and identify potentially suspicious activity. The project simulates some basic tasks performed by a Security Operations Centre (SOC) analyst.

## Key Features

- Brute-force detection: Identifies IP addresses with more than 5 failed login attempts.
- PowerShell analysis: Detects potentially suspicious commands, including EncodedCommand, DownloadString, and Invoke-WebRequest.
- IOC matching: Checks log entries against known malicious IP addresses and domains.
- Automated reporting: Generates a report highlighting suspicious IP addresses, potential attacks and investigation findings.

## Technologies Used

- Python
- Log analysis
- Threat detection
- Indicators of Compromise (IOCs)
- Security investigation and reporting
